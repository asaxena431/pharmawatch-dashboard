3. Redact

Files are processed in memory; the redacted copy is kept for 30 minutes so you can download it, then deleted.

How rules work

  • builtin – ready-made patterns: {{ builtins }}
  • keywords – list of words/phrases to remove (e.g. company or product names)
  • label – redact the value after a label, e.g. Patient Name: John Doe
  • regex – your own regular expression (use group to redact only part)
  • Set enabled: false to switch a rule off; replacement sets the text that replaces it.
